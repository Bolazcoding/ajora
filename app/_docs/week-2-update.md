## 1. What I Worked On

This week, I worked on making Ajora more organised and functional. I built reusable components and connected the different dashboard sections to structured sample data.

- Improved the Dashboard Overview and contribution summaries.
- Worked on the Members and Payout Schedule sections.
- Added contribution records and relevant search and filtering features.
- Improved navigation and the overall user experience.
- Continued working with Next.js, TypeScript, and Tailwind CSS.

## 2. Key Decisions

I kept Ajora frontend-only and used sample data instead of introducing a backend or database. I also used reusable components to reduce repeated code and make the project easier to maintain.

## 3. Issue Log

### Issue 1: Keeping Dashboard Sections Consistent

- **Options considered:** Repeating markup or using reusable components.
- **Resolution:** Used reusable components and shared data structures where appropriate.

### Issue 2: Contribution Summary Calculations

- **Options considered:** Calculating totals separately or deriving them from contribution records.
- **Resolution:** Checked the calculations against the relevant contribution records.

### Issue 3: Search and Filtering

- **Options considered:** Filtering the displayed records or applying filters to the full list.
- **Resolution:** Reviewed the filtering logic to ensure search and filters return the expected results.

### Issue 4: Organising Payout Information

- **Options considered:** Keeping payout details together or separating them into a dedicated section.
- **Resolution:** Organised payout order, recipients, and upcoming payout information in the Payout Schedule section.

### Issue 5: Maintaining the Codebase

- **Options considered:** Keeping all logic inside page components or separating responsibilities.
- **Resolution:** Used reusable components and organised data handling to make the code easier to maintain.

## 4. Blockers

Ajora currently uses sample data, so it does not provide real backend storage or financial transactions. Any other outstanding issues will be documented as they arise.
