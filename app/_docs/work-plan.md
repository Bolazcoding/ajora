# Ajora — Three-Week Work Plan

**Track:** Frontend Development  
**Project:** AjoCircle  
**Stack:** Next.js, TypeScript, Tailwind CSS

## Week 1 — Foundations

**Goal:** Build and deploy the initial responsive screen with working interactivity.

Deliverables:

- Finalise the project idea one-pager and work plan.
- Maintain a public GitHub repository with a starter README.
- Build a responsive dashboard that works on mobile and desktop.
- Implement at least two JavaScript interactions.
- Handle empty or invalid input gracefully.
- Deploy the application and capture mobile and desktop screenshots.
- Sketch the key dashboard screen.
- Create the `week-1` Git tag.
- Prepare for a five-minute mentor presentation.

## Week 2 — Components and Data

**Goal:** Improve the application structure and make the interface data-driven.

Deliverables:

- Break the interface into reusable components.
- Organise member, contribution and payout information using mock data.
- Add search or filtering where appropriate.
- Implement loading, empty and error states where applicable.
- Record mentor feedback and document responses.
- Maintain an issue log containing bugs, decisions and fixes.
- Create the `week-2` Git tag.

## Week 3 — Quality and Delivery

**Goal:** Improve usability, accessibility, testing and project documentation.

Deliverables:

- Complete at least two routed views and a not-found page.
- Implement a stateful feature that works across views.
- Check keyboard navigation and accessibility.
- Record accessibility results before and after improvements.
- Add at least three automated tests.
- Finalise the README with setup instructions, scripts, decisions and limitations.
- Prepare a five-minute walkthrough video.
- Write a technical reflection and complete the project declaration.
- Create the `week-3` Git tag.

## Top Three Project Risks

1. **Data consistency:** Contribution statuses and payout information may become inconsistent across screens.  
   **Mitigation:** Use a clear mock-data structure and reusable components.

2. **Responsive usability:** Dashboard content may become crowded on smaller screens.  
   **Mitigation:** Test mobile and desktop layouts throughout development.

3. **Time management:** The planned features may exceed the three-week timeline.  
   **Mitigation:** Prioritise the core contribution-tracking flow before optional enhancements.

## Project Constraints

Ajora is a frontend prototype using mock/sample data. Real payments, bank integrations and production backend functionality are outside the current scope.
