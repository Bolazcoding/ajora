# Ajora — Project Idea One-Pager

**Track:** Frontend Development  
**Stack:** Next.js, TypeScript, Tailwind CSS

## Target User

Organisers and members of small rotating Ajo contribution groups who need a simple way to track contributions and payout turns.

## Problem

Managing an Ajo group through chats or spreadsheets can make it difficult to know who has paid, who has outstanding contributions, and whose turn it is to receive the payout. Ajora provides a central dashboard for tracking this information.

## Core Flow

View group overview → Track members and contributions → Check payout order and upcoming payout.

## Data Source

Mock/sample data for the frontend prototype.

## In Scope

- Dashboard with contribution summaries and upcoming payout information.
- Member list and payout-order tracking.
- Contribution statuses, including paid and pending contributions.
- Navigation between the dashboard and management screens.
- Responsive layouts for mobile and desktop.

## Out of Scope

- Real-money transfers or payment processing.
- Bank account integration.
- Production backend and database integration.
- Automatic collection of contributions.

## Top Three Risks

1. Keeping contribution and payout information consistent across screens.
2. Making the interface clear and usable across different screen sizes.
3. Completing the planned features within the three-week timeline.
